경주GO(Gyeongju GO) 개인정보처리방침

시행일자: 2026년 8월 24일

"경주GO"(이하 "앱")는 경주 지역 여행 정보 제공 및 관광 스탬프 투어 서비스를 위해 최소한의 정보만을 수집하며, 아래와 같이 개인정보를 처리합니다.

1. 수집하는 정보 및 수집 방법

앱은 별도의 회원가입 없이 익명 인증(Firebase Anonymous Authentication)을 사용합니다. 실명, 전화번호, 이메일 등은 수집하지 않습니다.

항목수집 시점목적
익명 계정 식별자(UID)앱 최초 실행 시 자동 생성친구/파티/진행도 저장을 위한 기기 식별
닉네임, 선택 캐릭터, 친구 코드사용자 설정 시친구 목록, 파티 기능 제공
게임 점수, 방문한 관광지 목록스탬프 획득 시스탬프북 진행도 저장 및 기기 변경 시 복원
언어 설정언어 선택 시다음 실행 시 동일 언어로 자동 표시
위치 정보(GPS)지도 사용 시 상시 / 위치공유 기능은 사용자가 직접 켠 경우에만지도 표시, 근처 명소 탐색, (선택) 친구에게 내 위치 공유
카메라QR 코드로 친구 추가 시QR 코드 인식. 촬영된 이미지는 저장/전송되지 않습니다.
AI 비서에 입력한 텍스트AI 챗봇/번역 기능 사용 시답변 생성 및 번역 처리 (자체 서버를 거쳐 OpenAI API로 전달, 별도 저장하지 않음)

위치공유 기능은 기본값이 꺼짐(OFF) 상태이며, 설정 화면에서 사용자가 직접 켜야만 친구에게 내 위치가 표시됩니다. 언제든지 다시 끌 수 있습니다.
